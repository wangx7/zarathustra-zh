# 查拉图斯特拉如是说（新译）

尼采《查拉图斯特拉如是说》（*Also sprach Zarathustra*）德文原著的中文新译。

译文力求两点：**准确**，不添原文没有的话，也不漏原文有的意思，双关、典故、句式节奏都尽量保留；**简净**，读来通畅自然。

## 翻译方法

1. 依德文原文独立译出。
2. 对照学界通行的 KSA 校勘本系统核查误读、漏译与底本异文（古登堡本个别排印错误据此改正）。
3. 只为双关和典故加注，置于篇末。

几个关键译名：Untergang 译「沉落」（兼取日落与毁灭二义），überwinden 译「超克」，Wille zur Macht 译「求权力的意志」，der letzte Mensch 译「末人」。详见 `术语表.md`。
